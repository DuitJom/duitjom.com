# DuitJom
### Personal Loan & Repayment Loan System

DuitJom is a comprehensive personal loan management platform designed to simplify loan applications, approvals, disbursements, and repayment tracking. The system provides a seamless experience for customers, administrators, and credit officers through a secure and automated workflow.

---

## 🚀 Features

### Customer Portal
- Online loan application submission
- Loan eligibility checking
- Upload supporting documents
- Loan status tracking
- Repayment schedule viewing
- Payment history tracking
- Profile and account management

### Loan Management
- Personal loan application processing
- Automated loan approval workflow
- Loan disbursement management
- Interest and installment calculation
- Loan lifecycle monitoring
- Early settlement handling

### Repayment Management
- Monthly installment tracking
- Automated repayment scheduling
- Outstanding balance monitoring
- Late payment management
- Repayment reminders and notifications
- Settlement and closure processing

### Administration
- Customer management
- Loan approval dashboard
- Credit assessment workflow
- Risk monitoring
- Reporting and analytics
- Audit trail and activity logging

### Security
- Secure authentication
- Role-based access control (RBAC)
- Data encryption
- Transaction logging
- OTP verification
- Compliance-ready architecture

---

## 🏗️ System Modules

| Module | Description |
|----------|-------------|
| Customer Management | Manage customer profiles and accounts |
| Loan Application | Submit and review loan applications |
| Credit Assessment | Perform loan risk and eligibility checks |
| Loan Approval | Approval workflow and decision making |
| Disbursement | Loan payout management |
| Repayment Management | Installment and payment tracking |
| Notification Service | SMS, Email and OTP notifications |
| Reporting | Operational and financial reports |
| Audit & Compliance | Activity logs and compliance records |
